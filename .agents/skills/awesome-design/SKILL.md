# Awesome Design Systems

Curated DESIGN.md files from world-class products.

## Available Design Systems

This skill includes reference design systems from:
- **Vercel** (see DESIGN.md) - Clean, minimal, monochrome
- Linear, Stripe, Loom, and more available at https://github.com/VoltAgent/awesome-design-md

## How to Use

1. Read the bundled DESIGN.md for the design system closest to what the user wants
2. Apply its color tokens, typography scale, spacing, and component patterns
3. When user says "make it look like X", fetch that brand's DESIGN.md from the repo

## Usage Triggers

Use this when the user asks to:
- "Make it look like Vercel / Linear / Stripe"
- "Apply a clean design system"
- "Use a professional design system"
